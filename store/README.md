# App Store assets

Generated by `docs/tools/make_store_shots.py` from simulator captures. Folder names match App Store Connect slots:

| Folder | Size | Slot |
|---|---|---|
| `en/6.9`, `tr/6.9` | 1320 × 2868 | iPhone 6.9" (required) |
| `en/6.5`, `tr/6.5` | 1242 × 2688 | iPhone 6.5" (optional, Apple scales from 6.9") |

All PNGs are flattened RGB (no alpha channel). Order in the store: 01 leaning, 02 upright, 03 today, 04 lock screen, 05 watch, 06 welcome.

Regenerate:

```sh
python3 docs/tools/make_store_shots.py --lang en --src <captures> --out store/en
python3 docs/tools/make_store_shots.py --lang tr --src <captures> --out store/tr
```

`<captures>` holds raw simulator screenshots named `leaning.png`, `upright.png`, `welcome.png`, `lock.png` (iPhone, 1206 × 2622) and `watch.png` (Apple Watch).
